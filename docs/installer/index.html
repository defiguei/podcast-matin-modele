Installe ton podcast du matin

Chaque matin, un épisode audio rien que pour toi. Compte une dizaine de minutes : tu crées deux comptes gratuits, tu colles deux jetons, la page fait le reste.

  • Un compte GitHub
  • Un compte Cloudflare
  • Gratuit, sans carte bancaire

Le jeton GitHub de ton bot

Ton bot s'en sert pour lancer tes épisodes et installer les mises à jour.

  1. Touche le bouton : le nom et les permissions sont déjà remplis.
  2. Dans Repository access, choisis Only select repositories puis podcast-matin.
  3. Touche Generate token, puis copie le jeton (il commence par github_pat_).

3

Le jeton Cloudflare

Cloudflare héberge gratuitement ton bot, ton application et tes épisodes.

  1. Pas encore de compte Cloudflare ? Crée-le (gratuit, sans carte bancaire). S'il te demande de confirmer ton adresse e-mail, fais-le.
  2. Touche le bouton : la liste doit contenir Workers Scripts · Edit.
  3. Touche Continue to summary, puis Create Token, et copie le jeton (il n'est montré qu'une fois).
Créer le jeton Cloudflare ↗
La liste ne contient pas « Workers Scripts · Edit » ?

Dans API Tokens, touche Create Token, puis le modèle Edit Cloudflare Workers › Use template. Dans Zone Resources, choisis All zones, puis Continue to summary › Create Token.

4

L'installation

La page range tes jetons dans ton dépôt, met ton bot en ligne et te donne le code pour ouvrir l'application. Compte trois minutes : garde la page ouverte.

    C'est prêt 🎉

    Ton application :

    Scanne ce code avec l'appareil photo de ton téléphone.

    Ton code de connexion

    Un appareil est déjà connecté : pour en ajouter un, touche Afficher un code dans l'application (Réglages › Application).

    Ouvrir l'application
    iPhone : dans Safari, touche Partager › « Sur l'écran d'accueil », ouvre l'application depuis l'icône, puis entre le code. C'est là que les notifications marchent.
    Android : dans Chrome, le code est déjà rempli ; Chrome propose ensuite d'installer l'application.

    Au premier lancement, l'application te guide : ton prénom, ta ville, l'heure de l'épisode, ton agenda et ta clé Gemini (gratuite).

    Tes jetons ne quittent pas ce navigateur, sauf vers GitHub (chiffrés, pour les secrets de ton dépôt). La page ne garde rien : la recharger efface tout.
